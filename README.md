# 2026 파주 과학·융합축제 과학잼(JAM) 안내 사이트

정적 웹사이트입니다. 빌드 도구 없이 HTML/CSS/JS 파일만 있으면 돌아가므로,
VS Code에서 열어 바로 이어서 작업할 수 있습니다.

## 실행 방법

1. VS Code에서 이 폴더를 엽니다. (`파일 → 폴더 열기`)
2. 확장 **Live Server**를 설치합니다.
3. `index.html`에서 우클릭 → **Open with Live Server**.

Live Server 없이 `index.html`을 더블클릭해도 대부분 정상 동작하지만,
로컬 서버로 여는 쪽이 PDF 다운로드·지도 삽입 시 안전합니다.

## 폴더 구조

```
paju-science-jam/
├─ index.html            ← 축제 안내 페이지 (섹션별 주석 있음)
├─ stamp.html            ← 참가자용 스탬프판
├─ admin.html            ← 운영 관리 페이지 (비밀번호 잠금)
├─ css/
│  ├─ style.css          ← 색·간격·반응형. 맨 위 :root 에서 색을 한 번에 변경
│  └─ app.css            ← 스탬프판·관리자 페이지 전용 스타일
├─ js/
│  ├─ main.js            ← 메뉴, 스크롤 효과, 부스 검색/필터
│  ├─ stamp.js           ← 스탬프 찍기 동작
│  ├─ admin.js           ← 부스 비밀번호 관리, 기념품 확인, 설정 파일 생성
│  └─ hash.js            ← 비밀번호 해시 계산 (수정할 일 없음)
├─ data/
│  ├─ booths.js          ← ★ 부스 목록 데이터
│  └─ config.js          ← ★ 스탬프 투어 설정 (비밀번호 해시, 기준)
└─ assets/
   ├─ img/               ← 엠블럼(잼 단지) 이미지, 파비콘
   └─ pdf/               ← 리플렛·부스 설명서 PDF 넣는 곳
```

## 자주 고칠 곳 체크리스트

| 할 일 | 파일 | 위치 |
|---|---|---|
| 부스 목록 교체 | `data/booths.js` | `BOOTHS` 배열 전체 |
| 부스 설명서 PDF 연결 | `assets/pdf/` | `booth-guide.pdf` 이름으로 저장 |
| 문의 전화번호 | `index.html` | 맨 아래 `footer__meta` |
| 장소·시간 변경 | `index.html` | 히어로 `hero__facts`, `about`의 `info-list` |
| 행사장 배치도 | `index.html` | `#zone`의 `zone--map` 카드 (이미지로 교체) |
| 브랜드 색 변경 | `css/style.css` | 파일 최상단 `:root` |

### 1. 부스 설명서 PDF 넣기

취합한 PDF를 `assets/pdf/booth-guide.pdf` 로 저장하면
상단 버튼과 부스 섹션 하단 버튼이 모두 그 파일을 내려받습니다.
파일명을 바꾸고 싶다면 `index.html`에서 `assets/pdf/booth-guide.pdf`를 검색해 3곳을 함께 수정하세요.

### 2. 부스 목록 교체

`data/booths.js`의 `BOOTHS` 배열만 실제 선정 결과로 바꾸면 됩니다.
80개를 손으로 적기 번거로우면, 신청 취합 엑셀(한셀)을 CSV로 저장한 뒤
아래 순서의 열로 정리해 변환하면 편합니다.

```
code, field, school, team, title, desc, time, age
```

`field` 값은 반드시 `과학` / `수학` / `생태환경` / `AI·디지털` 중 하나로 적어야
필터 버튼이 정상 동작합니다.

### 3. 지도 넣기

`index.html`의 `<div class="loc__map" id="map">` 안쪽 내용을 지도 iframe으로 교체하세요.

```html
<iframe src="지도 임베드 주소" title="운정호수공원 위치" loading="lazy" allowfullscreen></iframe>
```

카카오맵은 [지도 퍼가기](https://map.kakao.com) 기능으로, 구글 지도는 `공유 → 지도 퍼가기`로
iframe 코드를 얻을 수 있습니다.

## 스탬프 투어 사용법

### 기본 비밀번호 (행사 전에 반드시 바꾸세요)

| 용도 | 기본값 |
|---|---|
| 관리자 페이지 | `jam-admin-2026` |
| 부스 인증 | `jam-a01`, `jam-b03` … (부스 코드 기준) |
| 플로깅 인증 | `jam-plogging` |

### 현장 진행 흐름

1. **참가자**: 안내 부스 QR 또는 `주소/stamp.html` 로 스탬프판을 엽니다. 이름을 적으면 끝입니다.
2. **부스**: 체험이 끝나면 참가자 휴대폰의 `스탬프 받기` → 부스 선생님이 그 부스 비밀번호를 입력합니다.
   같은 부스에서 두 번은 찍히지 않습니다.
3. **플로깅**: 운영본부에서 수거물을 확인하고 플로깅 비밀번호를 입력합니다(최대 3회).
4. **기념품**: 조건을 채우면 참가자 화면에 `ABC123-9F2C` 형태의 인증번호가 뜹니다.
   운영본부에서 `admin.html → 기념품 확인`에 입력해 확인하고 수령 처리하면, 같은 번호로 두 번 받을 수 없습니다.

### 관리자 페이지에서 하는 일

- **부스 비밀번호**: 부스 목록에서 한 번에 불러와 비밀번호 자동 생성 → 인쇄하여 부스별로 배부, CSV 저장
- **기념품 확인**: 인증번호 검증, 수령 기록 및 CSV 저장
- **설정**: 분야별 기준 개수, 전체 최소 개수, 플로깅 횟수, 관리자 비밀번호 변경

### 바꾼 내용을 참가자에게 반영하려면

관리자 페이지의 변경 사항은 **그 기기에만** 저장됩니다. 실제 반영은 아래 한 단계가 더 필요합니다.

1. `admin.html → 설정 → config.js 내려받기`
2. 내려받은 파일로 서버(또는 폴더)의 `data/config.js` 를 덮어쓰기
3. 참가자는 페이지를 새로고침

### 꼭 알아두실 점

- 서버가 없는 정적 사이트라 **관리자 잠금은 간단한 잠금**입니다. 소스를 볼 줄 아는 사람은 우회할 수 있으니
  개인정보·대외비는 넣지 마세요. 스탬프 투어 정도의 용도에는 충분하지만, 실제 인증이 필요하면
  구글 앱스 스크립트나 Firebase 같은 백엔드를 붙여야 합니다.
- 스탬프는 **참가자 휴대폰의 브라우저**에 저장됩니다. 시크릿 모드로 열거나 브라우저 기록을 지우면 사라집니다.
  안내문에 "행사 중에는 페이지를 닫지 말아 주세요" 문구를 넣어두면 문의가 줄어듭니다.
- 참가자별 스탬프 현황은 서버에 모이지 않으므로, 전체 통계가 필요하면 수령 기록 CSV를 활용하세요.

## 배포

정적 파일이라 어디에 올려도 됩니다.

- **GitHub Pages**: 저장소에 올리고 `Settings → Pages → Deploy from a branch` 선택
- **Netlify / Vercel**: 폴더를 그대로 드래그 앤 드롭
- **학교·교육지원청 홈페이지**: 폴더 전체를 웹서버에 업로드
